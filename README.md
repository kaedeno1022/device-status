# ブラウザ端末モニタ (device-status)

閲覧中のブラウザ端末の通信状況とデバイス状況を1画面で表示する静的Webページ。ビルド不要で、`index.html` と `logic.js` の2ファイルだけで動く。

## 表示する内容

* 応答時間の推移（直近40回・5秒間隔）と接続イベント（切断・復旧・回線の変化）
* 回線速度の測定（ボタンを押した時だけ実行。下り・上りを各5秒）
* ネットワーク・端末・画面/表示・メモリ/ストレージの各情報
* ページ読み込みの内訳（このページを開いた時の実測）
* グローバルIPとプロバイダ

ライト/ダークテーマに対応する。

## 使い方

公開ページを開くだけでよい。手元で動かす場合は、ブラウザが `file://` では別ファイル（`logic.js`）の読み込みを拒否するため、HTTPサーバー経由で開く。

```sh
python3 -m http.server
# 表示された URL（通常 http://localhost:8000）をブラウザで開く
```

## 外部通信とプライバシー

サーバー側の処理はなく、計測はすべてブラウザ上で行う。ただし次の外部サービスにアクセスする。

| 用途 | 宛先 | 送られる情報 |
| --- | --- | --- |
| グローバルIP・プロバイダ取得 | `ipinfo.io` | 閲覧者のIPアドレス（通信の性質上、相手に見える） |
| 回線速度測定 | `speed.cloudflare.com` | 測定用データの送受信（ボタン押下時のみ） |
| Webフォント | `fonts.googleapis.com` / `fonts.gstatic.com` | フォント取得リクエスト |

外部通信が制限された環境ではIP取得・速度測定は失敗し、画面上にその旨が表示される。

## ブラウザ対応

Network Information API・Battery Status API・`performance.memory` などは Chromium 系ブラウザのみ対応で、Safari/Firefox では該当項目が「—」表示になる。取得できない項目は判定なし（`na`）として扱う。

## 開発

```sh
npm test   # Node.js 標準のテストランナー（node --test）で logic.test.js を実行
```

* `logic.js` — 判定・整形のロジック。ブラウザAPIに触れないため単体テストできる
* `logic.test.js` — `logic.js` のテスト
* `index.html` — 画面と描画、ブラウザAPIの呼び出し
