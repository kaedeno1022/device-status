    グローバルIP・プロバイダ

    応答時間は、このページの配信元サーバーへ小さなリクエストを送り、返ってくるまでの往復時間を実測した値。4 秒以内に返らなければ失敗として数える。

    下り帯域・RTT推定・回線品質は Network Information API の推定値で、Chrome 系ブラウザのみ対応。プライバシー保護のため下り帯域は 10 Mbps、回線品質は「4G相当」が上限に丸められる。実際の回線速度の計測（スピードテスト）ではない。

    回線速度の測定は、ボタンを押した時だけ外部サービス speed.cloudflare.com との間でデータを送受信して行う。下りを5秒、続けて上りを5秒測る。測定値は相手サーバーの混雑や経路の影響を受けるため、契約速度の上限を示すものではない。

    グローバルIP・プロバイダは、ボタンを押した時だけ外部サービス ipinfo.io に問い合わせて取得する。外部への通信が制限された環境（claude.ai 上の公開ページなど）では取得できない。

    このページは index.html と logic.js の2ファイルで動く。手元で開く時は、ファイルを直接ダブルクリックせず、置いたフォルダで python3 -m http.server を実行して表示された URL から開く（ブラウザが file:// では別ファイルの読み込みを拒否するため）。

    「取得不可」はブラウザがその情報を公開していない項目。Safari・Firefox では多くの項目が取得できない。
